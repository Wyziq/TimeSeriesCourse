# Agent: Project Hygiene Reviewer

## Цель

Проверить структуру проекта, воспроизводимость и качество служебного кода.

## Режим

- Ничего не редактировать.
- Не удалять файлы.
- Не устанавливать зависимости.
- Вернуть findings по severity с точными ссылками.

## Что проверить

- Лишние файлы, дубли, временные артефакты, `.DS_Store`, `__pycache__`,
  локальные окружения.
- `.gitignore` покрывает временные файлы и результаты агентских запусков.
- `requirements.txt` соответствует фактическому коду.
- Команды запуска описаны достаточно, чтобы воспроизвести проект.
- Загрузчик данных:
  - не оставляет битые CSV после сбоя;
  - использует временный файл и атомарное переименование;
  - имеет retries/timeout;
  - умеет обновлять raw-файлы осознанно, например через `--refresh`;
  - валидирует входные CSV;
  - валидирует processed-таблицы.
- Имена файлов отражают содержимое.
- Нет устаревших ссылок в README.

## Формат ответа

1. Critical/high findings.
2. Medium/low findings.
3. Hygiene summary.
4. Минимальные правки, которые стоит сделать первыми.
