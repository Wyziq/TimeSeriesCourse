# Project Review Agents

В этой папке хранятся шаблоны независимых проверок проекта. Их цель — быстро
проверять, что работа соответствует заданию, данные не создают методологических
ошибок, а код и структура проекта остаются воспроизводимыми.

Шаблоны можно использовать как промпты для субагентов или как ручной чек-лист.
Сами шаблоны хранятся в репозитории. Результаты запусков, черновики и логи
складываются в `agents/runs/` или `agents/tmp/` и игнорируются Git.

## Агенты

- `assignment-compliance.md` — проверка соответствия требованиям `homework.md`.
- `data-methodology.md` — проверка данных, временных рядов и рисков утечки.
- `project-hygiene.md` — проверка структуры, кода и воспроизводимости.

## Как запускать аудит

1. Запустить подготовку данных:

   ```bash
   conda run -n timeseries python scripts/prepare_jolts.py
   ```

2. Передать каждому агенту его markdown-файл как инструкцию.
3. Попросить агента ничего не редактировать и вернуть findings по приоритету.
4. Свести результаты в общий список задач.
